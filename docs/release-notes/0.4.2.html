ChatGPT Vault, Turbo & Bridge v0.4.2

  • Fixes the Control Center update-check path by separating a published update from an XPI that Firefox has actually staged.
  • Adds a best-effort, cache-busted read of the public update manifest so throttled Firefox checks no longer look like a dead button.
  • Adds bounded automatic retries when Firefox reports a published update but has not staged it yet.
  • Install Update now reloads only after Firefox confirms the signed XPI is staged.

  • Refuses native downgrades and remains in Maintenance Mode if native repair fails.
